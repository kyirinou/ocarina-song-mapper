# Changelog

## 0.2.0 — Unreleased

- Add repeatable unit and browser regression tests, reproducible build checks, and a GitHub Actions workflow that gates its Pages deployment on checks.
- Add versioned project handling and recovery protection, with tests for storage failure, malformed projects, legacy compatibility, and save/restore behavior.
- Separate pure music and persistence rules into explicit modules while preserving the browser and offline builds.
- Add accessibility checks, contributor instructions, browser/device test guidance, issue forms, privacy documentation, and a release process.
- Update jsPDF from 3.0.4 to 4.2.1 and record bundled dependency versions, source integrity, licenses, and remaining maintenance items.

The release remains a local candidate until its commit has passed the hosted workflow and the release matrix has recorded actual results.

## Earlier development

Earlier versions were published directly to GitHub Pages. The Git history records their score editor, practice tools, fingering recognition, piano roll, page editor, and offline builds. Those commits do not have formal versioned release notes.
